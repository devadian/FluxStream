## 📦 Download & Installation

Grab the latest build from the [**Releases**](https://github.com/devadian/FluxStream/releases/latest) page:

- **Android (`APK`):** Download `FluxStream-v*.apk`, allow **Install unknown apps** if prompted, and install directly. Earlier signed releases update cleanly in-place without losing your history or activation.
- **Windows (`Setup EXE` — Recommended):** Download `FluxStream-v*-windows-x64-setup.exe` and run the installer to add **FLUX STREAM** to your Start Menu &amp; Desktop automatically.
- **Windows (`Portable ZIP`):** Extract `FluxStream-v*-Windows-x64.zip` and launch `fluxstream.exe`.

> **Note:** An active **FLUX STREAM Activation Key** is required to stream and download content inside the app.
