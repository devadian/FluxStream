## ✨ Features

| Feature | Description |
| :--- | :--- |
| 🏠 **Curated Home Feed** | Browse Trending, Cinema, Popular Worldwide, K-Drama, Anime &amp; Hot Short TV with smooth poster rails |
| 🔍 **Smart Search &amp; Recent History** | Instant live suggestions, Recent Searches history &amp; `Ctrl+F` quick focus on Windows |
| 🎬 **Powerful Native Player** | Smooth playback with multi-quality switching (`360p`–`1080p+`), crisp outlined subtitles, audio boost up to `200%` &amp; Voice Clarity |
| 🪟 **Floating Mini Player** | Keep watching while browsing Home, Search or Library — jump straight back to the full player anytime |

| 🎨 **Dark, Light &amp; Pure Black Themes** | Signature Dark theme by default, full Light &amp; OLED Pure Black modes, custom accent colors, and Android PiP support |
